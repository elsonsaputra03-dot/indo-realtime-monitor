Real BigQuery project. Produced by bqgov run against a real BigQuery sandbox project, read from INFORMATION_SCHEMA and the Tables API. It holds two small sample warehouses: e-commerce tables copied from bigquery-public-data.thelook_ecommerce, and a telco warehouse (tel_*) whose rows are generated in SQL, so the network data is synthetic while the jobs, costs, lineage and checks are real. Dollar amounts are tiny because the warehouses are tiny; the method is the same at any scale. Emails are replaced by stable ids.
