Featured project

Personal project · live snapshot updated hourly, full stack runs via Docker Compose

Indonesia Realtime Monitor

An end-to-end data platform that ingests public Indonesian data in near real time (earthquakes, wildfire hotspots, air quality, food prices, and news), checks its quality continuously, and lets anyone ask questions about it in plain Indonesian through a local AI.

The public demo is a static snapshot rebuilt every hour by GitHub Actions (zero hosting cost). The complete platform, including Kafka, ClickHouse, Airflow, data quality checks, and the local AI, is in the repository and runs on a single machine with Docker Compose.

Data quality that caught real issues

DQ checks flagged a misconfigured API key, duplicate events after restarts, and backfill lag, each fixed and documented.

Local LLM with guardrails

News classification and geotagging on a 4 GB laptop GPU (Ollama). The model extracts place names only; coordinates always come from a gazetteer of 38 provinces and 514 regencies.

Ask the data, safely

Tool-calling Q&A: the AI picks predefined queries, never writes SQL. Numbers are computed by the system and shown next to every AI answer.
